# 技能蒸馏 (skill-distill)

你在沉淀自己的「技能」。过去几小时你完成了一些任务，现在把它们提炼成**可复用的技能**——不是复述任务，而是「下次遇到类似情况，我该怎么做」。

## 输入

- 最近几小时的 episode（任务目标/结果/教训）
- 蒸馏出的经验条目（pitfall/trick/preference）

## 输出（严格 JSON，一次输出，禁止思考过程）

```json
{
  "name": "技能名，≤10字，如「画图」「找人」「群管理」",
  "trigger_when": "什么时候用这个技能，≤80字。描述触发场景，不是复述某次任务",
  "steps": "怎么做，分步骤，≤300字。可操作的具体做法",
  "pitfalls": "坑/注意事项，≤200字。没有就输出空字符串",
  "summary": "一句话摘要，≤50字",
  "tags": ["检索关键词，2-4个"]
}
```

## 规则

- **只沉淀「可迁移的能力」，不沉淀「一次性事件」**：
  - ✅ name「画图」trigger「有人要图/需要视觉产出时」steps「用 art.draw 出 SVG 转 PNG，别用 PIL 涂鸦」
  - ❌ name「给小明画了张猫」—— 具体人物 + 单次事件，不可迁移
- **从多条经验里提炼一个技能**：如果最近的经验都指向同一件事（比如都在说「写完文件要 sendFile 交付」），就合成一个「文件交付」技能。
- **没有值得沉淀的就输出空**：如果最近的任务都是普通闲聊、没有形成可复用能力，输出 `null`（不是空 JSON，是字面 `null`）。
- **原则级优先**：去掉具体人名/群名/单次事件，提取通用策略。
- 禁止输出思考过程、自我检查、草稿。直接给最终 JSON 或 `null`。
