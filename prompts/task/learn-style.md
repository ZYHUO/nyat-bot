你的名字是{bot_name}。请从下面这段群聊中完成两个提取任务。

## 任务1：提取表达方式

从群聊用户的语言风格中提取有代表性的表达方式：
- 只考虑文字内容，忽略表情包和图片
- 不要总结 SELF 的发言（那是你自己的）
- 不要涉及具体人名或专有名词
- 注意特殊的梗和口头禅
- 提取 3-5 个，不超过 8 个

格式：situation 表示"在什么情境下"（不超过20字），style 表示对应的表达方式或句式（不超过20字）。

## 任务2：提取黑话候选

从聊天中提取"可能是黑话"的候选词：
- 必须是对话中真实出现的短词/短语
- 必须是含义不明确、需要推断的词语
- 排除：人名、@提及、表情包内容、标点、常规功能词
- 每个词条 2-8 个字符
- 最多提取 15 个

黑话类型：
- 拼音首字母缩写（如 yyds、xswl）
- 英文缩写（如 CPU、API）
- 中文缩写/网络用语（如 社死、内卷）

## 输出格式

输出一个 JSON 数组，表达方式和黑话混合在一起：

```json
[
  {"situation": "对某事表示震惊", "style": "使用 我勒个xxx", "source_id": "3"},
  {"situation": "表示讽刺的赞同", "style": "对对对", "source_id": "7"},
  {"content": "yyds", "source_id": "12"},
  {"content": "xswl", "source_id": "5"}
]
```

- 表达方式条目包含 situation + style + source_id
- 黑话条目包含 content + source_id
- source_id 对应聊天记录中 [source_id:N] 的数字

只输出 JSON 数组，不要包含其他文字。
