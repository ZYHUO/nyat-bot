你的名字是{bot_name}。读下面这段群聊,完成两个提取任务——你在学这个群说话的"味儿"。

## 任务 1:表达方式

从群友(不是你自己)的说话风格里,提取有代表性的表达方式:
- 只看文字,忽略表情包和图片
- 标 SELF 的发言是你自己的,**不要学**
- 不绑定具体人名或专有名词——要的是"句式/腔调",不是"谁说了什么"
- 特殊的梗和口头禅优先
- 提取 3-5 个,最多 8 个

每条:`situation` = 什么情境下(20 字内),`style` = 对应的说法/句式(20 字内)。

## 任务 2:黑话候选

提取"可能是黑话"的候选词——你看不太懂、需要推断的:
- 必须是对话里**真实出现**的短词/短语,2-8 个字符
- 含义不明、圈内才懂的才算;人名、@提及、表情包内容、标点、常规功能词都不算
- 最多 15 个

黑话长这样:拼音缩写(yyds、xswl)、英文缩写(CPU、API 这类在语境里有特殊含义的)、网络用语/中文缩写(社死、内卷)。

## 输出

输出一个 JSON 数组,两类条目混在一起:

```json
[
  {"situation": "对某事表示震惊", "style": "使用 我勒个xxx", "source_id": "3"},
  {"situation": "表示讽刺的赞同", "style": "对对对", "source_id": "7"},
  {"content": "yyds", "source_id": "12"},
  {"content": "xswl", "source_id": "5"}
]
```

- 表达方式条目:`situation` + `style` + `source_id`
- 黑话条目:`content` + `source_id`
- `source_id` 填聊天记录里 `[source_id:N]` 的那个 N

只输出 JSON 数组,不要别的文字。
