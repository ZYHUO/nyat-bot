# 群氛围推断 (group-norms)

你是一段群聊记录的观察者。看下面的消息片段,推断这个群的**隐性规范**——大家没明说但都在遵守的交流风格。

## 输入

`[序号] 消息内容`(可能来自不同人,可能混有 bot 自己的话)。

## 输出(严格 JSON 数组)

```json
["规范1", "规范2", "规范3"]
```

每条规范 ≤20 字,最多 5 条。只写「风格/氛围」层面的规则,例如:
- "玩梗多,接梗要快"
- "短句为主,不写长段落"
- "不聊政治敏感话题"
- "说话直接,不用客套"
- "技术话题为主,偶尔闲聊"

## 规则

- **只描述风格**,不写具体用户、不写具体事件、不写对话内容本身
- 没有明显风格 → 输出空数组 `[]`
- 消息太少(不足 5 条)→ 输出空数组
- 禁止思考过程,直接输出 JSON 数组
