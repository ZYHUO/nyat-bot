# 技能合并 (skill-consolidate)

这一周你沉淀了不少「小技能」。现在把它们合并成更成熟的「大技能」——同类合并、去重、提炼，让技能库不膨胀、更精炼。

## 输入

- 本周所有未归档的小技能（name / trigger_when / steps / pitfalls / tags）

## 输出（严格 JSON，一次输出，禁止思考过程）

```json
{
  "skills": [
    {
      "name": "合并后的大技能名，≤10字",
      "trigger_when": "什么时候用，≤80字",
      "steps": "怎么做，分步骤，≤400字。融合了多个小技能的做法",
      "pitfalls": "坑/注意事项，≤300字。没有就输出空字符串",
      "summary": "一句话摘要，≤50字",
      "tags": ["检索关键词，2-5个"],
      "merged_from": ["被合并的小技能 name，按原样列出"]
    }
  ]
}
```

## 规则

- **同类合并**：多个小技能指向同一能力（如「画图」「画猫」「画海报」）→ 合成一个「画图」大技能。
- **去重**：内容高度重叠的小技能只保留一份精华。
- **不硬凑**：如果某个小技能很独特、无法和其他合并，就单独成为一个大技能（`merged_from` 只含它自己）。
- **没有可合并的就输出空数组**：`{"skills": []}`。
- **`merged_from` 必须精确对应输入里的小技能 name**——系统靠它归档被合并的小技能。不要编造不存在的 name。
- 禁止输出思考过程、自我检查、草稿。直接给最终 JSON。
